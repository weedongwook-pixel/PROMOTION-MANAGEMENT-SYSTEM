ตั้งค่า Import (นำเข้าจาก Excel)

เปิด/ปิดปุ่ม “นำเข้าจาก Excel” (ดาวน์โหลด Template + Import จากไฟล์) บนฟอร์มแจ้งโปรโมชั่น — มีผลเฉพาะหน้า Item Set (Create Promotion) เท่านั้น · ตั้งค่าซิงค์ทุกเครื่อง

ฟังก์ชัน Import บนฟอร์ม Item Set
เปิด = โชว์แถบ “นำเข้าจาก Excel” บนหน้า Item Set · ปิด = ซ่อน (ค่าเริ่มต้น: ปิด)
หน้าฟอร์มอื่น (Coupon · Bill Discount · Voucher) ถอดฟังก์ชัน Import ออกถาวรแล้ว — การตั้งค่านี้ควบคุมเฉพาะหน้า Item Set
