ตั้งค่า Tender / EDC ต่อสาขา

Tender มาตรฐานที่เปิดบน POS + บันทึกว่าแต่ละสาขาใช้ EDC แบบไหน / ไม่ใช้

ขั้นตอนอนุมัติ (Workflow)

มาตรฐาน = เปิดบนเครื่อง POS หลักให้ใช้งานอยู่แล้ว พิเศษ/สำรอง = สาขาต้องแจ้งขอเปิดเอง (หน้า “แจ้งเปิด-ปิด Tender”) Interface = เครื่อง EDC ที่เชื่อมต่อกับ POS

รายการ Tender

EDC ที่แต่ละสาขาใช้

Import: คอลัมน์ Numeric Code (PCxxxx) · EDC Type (KPLUS/M-EDC/MALL/NONE) · Provider · TID · Model · SIM · Merchant Name · Install Date — รับ .csv / .xlsx · กด Template เพื่อดาวน์โหลดไฟล์ตัวอย่าง
รหัสสาขาEDC ที่ใช้ผู้ให้บริการ / ธนาคารหมายเหตุ

ผูกผู้ใช้ OP กับโซน (Zone = key จับคู่)

จับคู่ด้วย เลขโซน (คงที่ ไม่เพี้ยนเหมือนชื่อ) · ใส่ชื่อผู้ใช้ OP ที่ดูแลแต่ละโซน (คั่นด้วย ,) · กำหนดที่หน้า จัดการผู้ใช้ ก็ได้ · Area เห็นเฉพาะสาขาในโซนตัวเอง

โซน / Area ผู้รับผิดชอบสาขา

ไฟล์ต้องมีคอลัมน์: Alpha Code · Numeric Code (PCxxxx) · Store Name · Grade · ZONE · NAME (Area) · Tel. — รับได้ทั้ง .csv / .xlsx · กด Template เพื่อดาวน์โหลดไฟล์ตัวอย่าง · นำเข้าแล้วอัปเดททับตามรหัสสาขา (เบอร์มือถือสาขาไม่ถูกแตะ)
รหัสสาขาโซนAreaเกรดเบอร์ AreaมือถือสาขาTIDสถานะเครื่อง

e-Payment ต่อสาขา (TrueWallet · Alipay · WeChat · ShopeePay)

มีทุกสาขา · แก้ทีละสาขาได้ (ปุ่มดินสอ) หรือ Import ไฟล์ (.csv / .xlsx) ครบทุกช่อง (TrueWallet · Alipay · WeChat · ShopeePay) · กด Template เพื่อดาวน์โหลดไฟล์ตัวอย่าง · สาขาไหนไม่มีเลขขึ้น "ไม่พบ" สีแดง
