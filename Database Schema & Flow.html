0. โครงสร้างที่ระบบสร้าง/เก็บจริง REAL — ตรงกับโค้ด

ระบบเก็บข้อมูลจริงเป็น key/value JSON blob — ทุก "ตาราง" คือ 1 key (pc_*) ใน localStorage ของเบราว์เซอร์ แล้ว sync ขึ้น Cloudflare D1 (ตารางเดียว promo_store(k, v, updated_at)) ผ่าน Worker · v = JSON ของ store นั้นตรง ๆ (ไม่แปลง/ไม่ตัดทิ้ง)
D1: promo_store = k (PK)v (JSON blob)updated_at (epoch ms)
งานโปรฯ (pc_mock_store_v28) ยัง แตกเป็น key ราย campaign (promo::c::<ชื่อ> + promo::meta) เพื่อให้ MKT/IT/OP หลายคนแก้คนละแคมเปญพร้อมกันโดยไม่ทับกัน · fields ด้านล่างคือ ชื่อฟิลด์จริงในโค้ด (js/mock-backend.js, js/code-counter.js ฯลฯ)
