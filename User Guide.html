หัวข้อ
ตั้งค่าแจ้งเตือน แจ้งเตือนเข้าปฏิทิน Brand Manager บัตรสมาชิก จัดการโค้ด แจ้งปัญหาสาขา

เริ่มต้นใช้งาน

คู่มือนี้อธิบายการตั้งค่าแต่ละส่วนแบบทีละขั้น สำหรับผู้ที่ไม่คุ้นเคย · ทุกหน้าตั้งค่า กดบันทึกเก็บในเครื่อง และมีผลกับทั้งระบบ · ป้ายด้านล่างบอกว่าฟีเจอร์ไหน “ใช้ได้จริงแล้ว” หรือ “เป็นตัวอย่าง flow” (ต้องให้ IT เชื่อมระบบจริงก่อน)

ใช้ได้จริงตัวอย่าง · รอเชื่อมระบบจริง
ตั้งค่าการแจ้งเตือน
เลือกว่าแต่ละเหตุการณ์จะแจ้งไปทางไหน + กลุ่มไหน
สำหรับ: Admin / ITตัวอย่าง (ยังไม่ยิงเมล/LINE จริง)
  1. ดูตารางเหตุการณ์
    แต่ละแถวคือ 1 เหตุการณ์ในระบบ (เช่น แจ้งเพิ่มโค้ด, โค้ดใช้ไม่ได้ที่ POS)
  2. เลือกช่องทาง
    กดปุ่ม Email / Team Chat / LINE ให้ติด (เลือกได้หลายอัน)
  3. เลือกกลุ่มปลายทาง
    พอเปิด Team Chat/LINE จะมีชิปให้เลือกว่าจะส่งเข้า “กลุ่มไหน” — กดเลือกได้หลายกลุ่ม หรือกด + เพิ่มกลุ่ม สร้างใหม่
  4. เพิ่มคนที่จะถูก @mention
    เลื่อนลงไปการ์ด “แผนก” → กด “เพิ่มสมาชิก” ใส่ชื่อ+อีเมล (คนกลุ่มนี้คือผู้รับเมล + ถูก mention)
  5. กดบันทึก
    ปุ่มเขียวด้านล่าง
อยากส่งเข้าอีเมลเดียว (ไม่ใช่ทั้งทีม)? ใช้ช่อง “ส่งเฉพาะอีเมลนี้” ในแถวเหตุการณ์นั้น
แจ้งเตือนเข้าปฏิทิน (Outlook / Google)
ส่งวันสำคัญเข้าปฏิทินพร้อมเตือนล่วงหน้า
สำหรับ: ทุกคน / ITICS + Google = ใช้ได้จริงเชื่อม M365/Google อัตโนมัติ = ตัวอย่าง
  1. เปิดสวิตช์ “เปิดแจ้งเตือนเข้าปฏิทิน” ด้านบน
  2. เลือกวิธี
    ICS (.ics) = ใช้ได้ทุกอีเมล โหลดไฟล์เปิดเอง · Microsoft 365 / Google Workspace = ลงปฏิทินอัตโนมัติ เฉพาะอีเมลบริษัท (ต้องให้ IT กดเชื่อมก่อน)
  3. เลือกเหตุการณ์ + สี
    เปิด/ปิดแต่ละอย่าง (โปรเริ่ม/หมด, โค้ดหมดอายุ ฯลฯ) และกดช่องสีเพื่อเลือกสีในปฏิทิน
  4. ตั้งเตือนล่วงหน้า
    กดชิป 7/3/1 วัน (เลือกได้หลายช่วง) + เลือกเวลาที่เตือน
  5. ทดสอบ
    กด “โหลด .ics” แล้วเปิดด้วย Outlook หรือ “เพิ่มเข้า Google Calendar” — จะเห็นนัดจริงพร้อมเตือน
โหมดอัตโนมัติ (M365/Google) ในตัวอย่างจะขึ้น “เชื่อมต่อแล้ว” แต่ยังไม่ยิงจริง จนกว่า IT จะลงทะเบียนแอป + ขอสิทธิ์ปฏิทิน
Brand Manager (หลายแบรนด์)
เพิ่มแบรนด์ · ธีม/โลโก้ · เปิด-ปิดโมดูล
สำหรับ: Adminตั้งค่า/สลับแบรนด์ = ใช้ได้จริง
  1. เลือกแบรนด์ จากรายการซ้าย เพื่อแก้ไข
  2. ตั้งชื่อ/โดเมน/สีธีม
    หรือ อัปโหลดภาพแบรนด์ ระบบจะดึงสีเด่นมาตั้งธีมให้อัตโนมัติ
  3. เปิด-ปิดโมดูล
    สวิตช์รายโมดูล — แบรนด์ไหนไม่ใช้ก็ปิด (เมนูจะซ่อนให้)
  4. กด “ใช้แบรนด์นี้”
    สลับมุมมองทั้งระบบไปแบรนด์นั้น (ข้อมูลแยกกันแต่ละแบรนด์)
  5. เพิ่มแบรนด์ใหม่ ปุ่ม “Add New” ด้านล่างรายการ
บัตรสมาชิก (Member Card Master)
สร้างบัตร + สิทธิ์/ส่วนลด + ออกโค้ดบัตร
สำหรับ: MKTสร้าง/Import/Template = ใช้ได้จริง
  1. เพิ่มบัตรใหม่
    กด “Add New Member Master” → เลือก เพิ่มเอง (กรอกชื่อ/ระดับ/ส่วนลด/สิทธิ์) หรือ Import (วางจาก Excel) หรือ โหลด Template ก่อน
  2. กรอกสิทธิ์
    พิมพ์ 1 บรรทัด = 1 สิทธิ์ (เช่น ส่วนลด 10%, ฟรี Upsize)
  3. แจ้งเพิ่มโค้ดบัตร
    บนการ์ดบัตร กด “แจ้งเพิ่มโค้ดบัตร” → ใส่จำนวน → ส่งเข้าคิวงานโค้ดให้ IT
Import: คัดลอกจาก Excel วางได้เลย ตามหัว Template (ชื่อ, tier, ส่วนลด, prefix, สิทธิ์, เริ่ม, สิ้นสุด)
จัดการโค้ดโปรโมชัน
MKT แจ้งเพิ่ม/ลบ · IT อัป Backoffice · สาขาตรวจสอบ
MKT / IT / สาขาใช้ได้จริง (ตรวจไฟล์/ออกไฟล์)
  1. MKT แจ้งเพิ่มโค้ด
    เลือกแคมเปญ/ปุ่ม → แนบไฟล์โค้ด → ระบบตรวจซ้ำ/format ให้ (ซ้ำ/ผิดถูกตัดออก สรุปจำนวนที่เข้า) → ยืนยัน
  2. IT คิวงานโค้ด
    คัดลอก Code Promotion ไปค้นใน CMPOS · โหลดไฟล์ ProID/ProStatus/ProExpire ไปอัป Backoffice → กด “ยืนยัน+แจ้งเตือน”
  3. สาขาตรวจสอบโค้ด
    กรอกโค้ดจากลูกค้า → เจอ/ไม่เจอ → ถ้าใช้ไม่ได้ที่ POS กด “แจ้ง IT”
แจ้งปัญหาสาขา + ตามงานด่วน
สาขาแจ้ง → IT ตอบกลับ → สาขาปิดงาน
สาขา / ITครบลูป
  1. สาขาเปิด Ticket
    เลือกปัญหา + ใส่รายละเอียด → ยืนยันตัวตน (ตามที่ตั้งใน Report Settings) → ส่ง
  2. ติดตามใน Branch Tickets
    เห็นสถานะ + คำตอบจาก IT · มี SLA 1-4 ชม. และปุ่ม “ตามงานด่วน” (ยืนยันตัวตน + ใส่เหตุผล)
  3. IT ตอบกลับ
    หน้า Code Management แท็บ “แจ้งจากสาขา” → กดเลือก คำตอบสำเร็จรูป หรือพิมพ์เอง → แจ้งกลับสาขา
  4. สาขาปิดงาน
    เมื่อแก้แล้ว กด “ยืนยันแก้แล้ว ปิดเรื่อง” (ถ้า IT รับเรื่องแล้ว สาขายกเลิกไม่ได้)
